Privacy Policy – FoodMetric

Last updated: 2026-09-06 · Contact: support@foodmetric.app

FoodMetric (com.foodmetric.app) analyzes meal photos for nutrition.

  1. Photos: uploaded to a private temporary bucket for instant inference (NVIDIA / Groq / OpenRouter via Supabase Edge Function) and automatically deleted immediately after analysis. Never retained. AI providers process the image only to produce the analysis.
  2. Account: email via Supabase Auth, stored encrypted.
  3. Nutrition data: analyses + goals stored in Supabase Postgres with row-level security, deletable via Profile → Delete.
  4. Ads: Google AdMob (App ID ca-app-pub-9792230951056922~3353774222) uses the Advertising ID; formats: banner, interstitial, rewarded, native, app-open. Consent via UMP, resettable in system settings.
  5. Processors: Supabase, NVIDIA, OpenRouter, Google. No sale of personal data.
  6. Rights: access, correct, delete via support@foodmetric.app. This app is not medical advice.
